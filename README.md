# Bearing fault diagnosis at equal retained dimensions

Research code and experimental evidence for the bearing fault diagnosis study. The complete supplementary package is provided under [Releases](https://github.com/22150017/A-comparison-at-equal-retained-dimensions/releases).

The release archive contains code, configurations, prediction-based evidence, provenance hashes, and a verification script. Raw PU and CWRU signals are not included; obtain them from the original dataset providers listed in the archive README.
